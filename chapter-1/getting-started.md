# Getting Started

This guide will help you get started with GitBook.

## Installation

GitBook can be installed using npm:

```bash
npm install -g gitbook-cli
```

## Basic Commands

Here are some basic GitBook commands:

- `gitbook init` - Initialize a book
- `gitbook serve` - Serve a book for preview
- `gitbook build` - Build a book
- `gitbook pdf` - Generate a PDF version
- `gitbook epub` - Generate an ePub version
